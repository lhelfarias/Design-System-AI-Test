# AI context: how to design and build with this system

Read this folder before creating screens, components or code with this design system. It is written for AI agents and tools, and for people who brief them.

## Read in this order

1. `rules.md`: what you must and must not do.
2. `tokens.md`: where the values are and how they are named.
3. `components.md`: the components that exist, their properties and when to use them.
4. `patterns.md`: page anatomy, surfaces and device rules.
5. `figma.md`: how to work in the Figma files with the Figma connector or plugin API.

## Sources of truth

| What | Where |
|---|---|
| Token values | `packages/tokens/tokens.json` (edited only by pull request) |
| CSS variables | `packages/tokens/css/tokens.css` (generated) |
| Resolved values, flat list | `packages/tokens/dist/tokens.resolved.json` (generated by `npm run build`) |
| React components | `packages/react/src/components` |
| Visual style and devices | `docs/visual-style.md` |
| Layout, navigation, motion | `docs/layout.md`, `docs/navigation.md`, `docs/motion.md` |
| Figma library | "UI Kit – AI Test", file key `M0pBcAnDr1iLJXpcyZ2Epa` |
| Example screens | "Designs Examples", file key `ue2fi6XJwFxbNvAsiCIIvN` |

If two sources disagree, `tokens.json` and the docs in this repository win; report the difference.
