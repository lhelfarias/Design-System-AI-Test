# Spacing and layout

All spacing comes from a 4 px scale. Use system names by direction:

- **inset**: padding inside a box.
- **stack**: vertical gap between items.
- **inline**: horizontal gap between items.

## Sizes

`size.target-min` (44 px) is the minimum target for anything you can click or tap. WCAG 2.2 (2.5.8) asks for 24 px; 44 px is this system's decision.
